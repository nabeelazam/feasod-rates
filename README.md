# Feaso’d stamp duty rates

The signed stamp duty schedules the Feaso’d apps download to stay current. The apps only use a file whose
signature matches the publisher’s key and whose built-in check cases recalculate exactly; otherwise they keep
the rates they already have.

- `duty-rates.json`: the current schedules (general investor rates for each Australian state and territory).

Published from the Feaso’d source with `npm run rates`. Rates are indicative only; confirm duty with the
relevant state revenue office or a conveyancer.
